DDR: Diagram Done Right

DDR is an all-in-one editor for software engineers. Write diagrams as plain text in .ddr files and documents in .tdr files, and see the result live next to the code.

Features

  • Use case diagrams, flowcharts and architecture graphs from a short, readable text syntax.
  • Two-way editing: drag nodes, bend edges into straight or curved lines, and the code updates only that part.
  • Documents with embedded live diagrams, ready to print or save as PDF.
  • Export diagrams as SVG or PNG.
  • Works offline as an installable app. Projects stay in your browser.
  • Responsive layout with resizable panels on desktop and mobile.
